# 关系架构图验收清单

## 一、业务语义

- [ ] 所有用户确认的模块都已保留，没有因排版擅自删减。
- [ ] 每条关系的来源、去向和箭头方向与业务表达一致。
- [ ] 数据来源、知识调用、任务下发、执行结果和工作沉淀使用可区分的关系类型。
- [ ] 待确认内容有明确标记，没有把推测写成既定事实。
- [ ] 范围框只圈定真实所属模块，不把相邻调用或执行区域误算进去。

## 二、布局与文字

- [ ] 主阅读顺序不依赖长篇说明即可看懂。
- [ ] 分区之间有足够走线空间，卡片之间有稳定间距。
- [ ] 卡片、分组、标题、图例和范围说明没有叠层或遮挡。
- [ ] 长标题和最长业务词不溢出容器，按钮文字完整可见。
- [ ] 范围标签位于范围框内，且不与任何业务卡片相交。
- [ ] 窄屏只在画布视口内部横向滚动，页面主体不产生无意义溢出。

## 三、关系线

- [ ] 关系数据中的每条连接都生成了对应路径，没有孤立节点或指向已删除节点的连接。
- [ ] 业务路径只包含水平、垂直和直角转折，没有斜线。
- [ ] 所有主干线位于预留通道，未穿过非端点卡片、表格、标题或说明。
- [ ] 箭头真实落到目标卡片边缘，没有使用文字箭头代替连接。
- [ ] 长距离回流走外侧或底部总线，不进入中间业务卡片区域。
- [ ] 实线、虚线、颜色和图例的语义一致。
- [ ] 点击任一关键节点时，可以识别完整流转路径。

## 四、交互

- [ ] 鼠标悬停、键盘聚焦和点击均有清晰状态。
- [ ] 高亮只改变颜色、线宽或透明度，不改变布局尺寸。
- [ ] 点击节点能打开正确详情；详情内容与节点语义一致。
- [ ] 详情抽屉可以通过关闭按钮、遮罩和 `Escape` 关闭。
- [ ] 打印、全屏和导出类按钮名称与实际能力一致。

## 五、结构检查

- [ ] HTML 中没有重复 `id`。
- [ ] JavaScript 语法检查通过。
- [ ] 关系清单数量与生成路径数量可解释；共享主干不应被误算成业务关系。
- [ ] 重绘前会清除旧路径，连续缩放后没有重复线条。
- [ ] `load`、`resize`、`beforeprint` 和 `ResizeObserver` 会触发重绘。
- [ ] 范围框、SVG、标签和卡片的层级顺序稳定。
- [ ] 重要文件已有独立备份，本次差异只包含授权范围内的修改。

## 六、真实浏览器检查

至少检查以下三个视口：

| 视口 | 重点 |
|---|---|
| 目标汇报屏幕，例如 `1298 × 698` | 第一视口、横向阅读和主要关系 |
| 宽屏，例如 `1920 × 1080` | 整体比例、空白和长距离总线 |
| 窄屏，例如 `390 × 844` | 内部横向滚动、标题和按钮可用性 |

- [ ] 分别查看画布顶部、中部和底部，不能只截第一屏。
- [ ] 至少查看一个默认状态和一个路径高亮状态。
- [ ] 控制台错误为 `0`；警告应逐条说明是否影响交付。
- [ ] 本地预览地址返回成功状态，刷新后显示最新版本。
- [ ] 截图核对范围框、卡片、线路、标签和箭头，不以 DOM 数值代替肉眼检查。

## 七、打印或 PDF

- [ ] 纸张方向、缩放、页边距和页数符合交付要求。
- [ ] 打印预览中没有裁掉标题、说明、箭头或底部总线。
- [ ] 中文字体正常，没有乱码或字体替换导致的溢出。
- [ ] 若按钮声称“直接导出 PDF”，已验证真实文件生成和下载；否则改成“打印 / 另存为 PDF”。

## 验收结论

| 状态 | 判定 |
|---|---|
| `PASS` | 业务关系正确，无遮挡、穿线、斜线和报错，目标视口及交互均验证通过 |
| `WARN` | 存在已说明且不影响使用的限制，例如大图在窄屏需要横向滚动 |
| `BLOCK` | 关系方向错误、内容缺失、线穿卡、文字叠层、控制台报错或无法打开 |

交付时分别说明“结构检查”和“浏览器视觉检查”的结果。任何一项未执行，都不能写成已验证通过。
