# 关系架构图作图规则

## 1. 先建语义模型

绘图前先整理一张关系清单，不要直接在画布上试线。

| 字段 | 作用 |
|---|---|
| `id` | 节点和连线的唯一标识 |
| 分区 | 数据源、前台知识、调用、执行、沉淀等业务阶段 |
| 显示名称 | 卡片上的业务名称 |
| 来源 / 去向 | 箭头的起点和终点 |
| 关系类型 | 来源、调用、任务下发、执行结果、工作沉淀、回流 |
| 说明 | 线上标签、卡片摘要或详情抽屉内容 |
| 状态 | 已确认、待确认、未来能力 |

同一业务实体只保留一个语义。为了排版增加的中间节点只能作为走线枢纽，不能被误读为新业务模块。

## 2. 画布与分区

- 密集大图优先使用固定宽度横向画布，外层视口负责横向滚动。不要通过缩小字体把整张图硬塞进屏幕。
- 分区按业务顺序从左到右排列，常见顺序为“来源 → 可用知识 → 调用 → 执行 → 沉淀”。
- 分区标题、卡片和关系线必须使用同一坐标体系。标题位于分区上方，卡片在分区内部纵向排列。
- 推荐列距为 `56px` 至 `84px`。每增加一条独立主干通道，至少再预留 `16px` 横向空间。
- 大分组间距建议为 `24px` 至 `36px`，同组卡片间距建议为 `10px` 至 `14px`。
- 卡片圆角保持在 `4px` 至 `6px`，内容边距保持在 `12px` 至 `16px`；字号不随视口宽度缩放，字间距为 `0`。

### 范围框

当几个分区共同组成一个业务范围时，用浅色虚线大框圈定，不要把范围说明写成悬浮卡片。

- 范围框只包住实际属于该范围的分区和最后一个节点。
- 背景使用低透明度冷色，避免盖住关系线。
- 标签放在底部或侧边留白中，写清“范围名称”和“包含内容”。
- 框体尺寸应根据真实节点位置动态计算；内容高度变化时不能依赖固定像素猜测。

推荐层级：

| 层级 | 内容 | 推荐 `z-index` |
|---|---|---:|
| 背景 | 浅色范围框 | 0 |
| 连线 | SVG 总览线和高亮路径 | 1 |
| 说明 | 范围标签、线上标签 | 2 |
| 内容 | 分区、分组和业务卡片 | 3 |

## 3. 卡片表达

- 每张卡片只表达一个模块。标题说明“是什么”，摘要说明“做什么或包含什么”。
- 状态、角色、阶段等辅助信息使用小标签，不抢占主标题层级。
- 长说明进入详情抽屉或点击放大预览，主画布只保留扫描所需信息。
- 同一组的卡片使用一致尺寸；内容变长时允许换行，但不能挤压相邻模块或改变走线通道。
- 分组使用虚线边界和组标题，不把整个页面做成层层嵌套的卡片。

## 4. 正交连线

### 基本规则

- 业务关系只使用水平线、垂直线和直角转折，不使用斜线。
- 箭头从来源卡片边缘出发，落到目标卡片边缘；不能用文字中的“→ 01”代替真实连接。
- 相邻分区共用一条纵向主干，来源和目标通过水平支线接入。
- 主干只能放在列间走线通道中。若主干会穿卡，先扩大列距或调整节点位置。
- 来源与调用可使用实线；执行结果、反馈和工作沉淀使用虚线。颜色与线型要有图例，不能只靠颜色区分。

相邻分区的单条路径可按下面的方式生成：

```js
function orthogonalPath(start, end, trunkX) {
  return `M ${start.x} ${start.y} H ${trunkX} V ${end.y} H ${end.x}`;
}
```

路径命令应以 `M`、`H`、`V` 为主。箭头标记内部可以使用 `L`，但业务连接路径不得出现同时改变横纵坐标的斜线段。

### 长距离回流

跨越多个分区的回流统一走外侧或底部总线：

```text
来源卡片右侧
  → 最右侧外部通道
  ↓ 底部总线
  ← 目标分区外侧主干
  ↑ 目标节点纵坐标
  ← 目标卡片边缘
```

外部通道必须在所有卡片之外。多类回流可以使用平行总线，但要保持固定间距，不能随机错开形成线团。

### 总览线与高亮线

同一关系生成两层路径：

1. `network-segment`：默认显示的低对比度关系网。
2. `route-flow`：默认透明，选中节点后高亮的完整单条路径。

每条高亮线记录 `data-from` 和 `data-to`。节点被点击、聚焦或悬停时，激活直接相连路径，并按业务需要继续追踪上下游节点。

## 5. 动态定位

- 节点使用稳定且唯一的 DOM `id`。
- 通过 `getBoundingClientRect()` 读取节点位置，以左右边缘中点作为常用锚点。
- 如果 SVG 从画布标题下方开始，要统一扣除顶部偏移，不能在不同函数里重复猜测坐标。
- 在 `load`、`resize`、`beforeprint` 和画布尺寸变化时重新绘制。
- 使用 `ResizeObserver` 监听主画布，卡片内容变化后自动更新关系线和范围框。
- 每次重绘先移除动态生成路径，再生成总览线和高亮线，避免重复叠加。

## 6. 交互与可访问性

- 可点击节点使用语义化按钮，或同时提供 `tabindex="0"`、`role="button"` 和键盘操作。
- 悬停和键盘聚焦均可预览路径；点击锁定路径并打开详情抽屉。
- 详情抽屉支持关闭按钮、点击遮罩关闭和 `Escape` 关闭。
- 激活路径时降低无关总览线透明度，但不要让未选中的结构完全消失。
- 高亮不得改变卡片尺寸或触发布局位移。

## 7. 颜色与线型

使用克制的多角色配色，不用单一色族铺满整张图。可参考：

| 语义 | 参考色 | 用法 |
|---|---|---|
| 主结构 / 来源 | `#24476b` | 实线与主要标题 |
| 范围 / 数据源 | `#207579` | 浅底、虚线范围框 |
| 知识调用 | `#806923` | 调用路径和标签 |
| 回流 / 沉淀 | `#b75b2e` | 虚线回流路径 |
| 页面 | 白色与中性灰 | 背景、分隔和次要文字 |

范围框可以使用 `rgba(32, 117, 121, 0.30)` 虚线和约 `0.30` 透明度的浅底。卡片仍保持白色或极浅色，保证文字对比度。

## 8. 打印与 PDF

- 打印时固定画布比例，并根据目标纸张设置 `@page` 和缩放比例。
- 打印前重新计算连线，避免页面缩放后箭头错位。
- 使用 `window.print()` 时，按钮名称必须是“打印”或“另存为 PDF”。
- 若需求是点击后直接得到 PDF 文件，应实现真实文件生成和下载，并验证页数、方向、裁切和中文字体。
