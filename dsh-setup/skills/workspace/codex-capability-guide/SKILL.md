# Codex 能力与知识指南

本工作区有一份 2026-10-26 的本机资料快照。先读 [总览](../../../codex-能力与知识指南/00-总览.md)，再选择相关部分，不一次加载全目录。

- 技能选择：读 `01-技能目录.md`，找到原始 SKILL.md；references/、scripts/ 相对原技能目录解析。
- 插件、MCP、工具：读 `02-插件与工具边界.md`；Codex 启用不代表 DSH 已接通。
- Obsidian、BI、SAP、RAGFlow：读 `03-知识库读取指南.md`。
- 协作与交付：按需读 `04-协作约定.md`。
- 使用示例与兼容状态：读 `05-DSH使用与兼容说明.md`。

先确认本会话的工具、依赖、文件权限和服务，再执行需要动作的步骤。按用户既有约定，读取 Obsidian 永久记忆前先征求同意；本任务已明确授权时不重复询问。写入、提炼、上传和备份推送需要对应授权，不能从读取指南推导出来。

当前大肥鱼人设保留。引用旧业务资料要保留来源与日期，不把方案知识当作实时数据，不把整理完成说成所有工具已迁移。
