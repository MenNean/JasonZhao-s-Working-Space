# 决策：暂不安装第三方技能桥接插件

## 结论

不装。继续用已复制到 `~/.dsh/skills` 的 23 个技能；以后新增 Codex 技能按需手动复制指定目录。

## 候选与核查证据（2026-10-26）

| 候选 | 核查结果 | 判断 |
|---|---|---|
| `@dsh-skillport/bundle` | npm 上包名与 packument 均 404；仓库 issue #2「无法安装」至今 open；peer 依赖写 `@deepseek-ai/dsh-* ^0.1.0-rc.6`，宿主是 0.2.1-rc.3；仓库最后推送 2026-08-28 | **装不了**，且跨大版本不保证 |
| `dsh-plugin-codex-bridge` | npm 有 0.1.1，可装、零配置、无 peer 约束；但 2★、最后提交 2026-08-14、仅 13.8KB；会注入 `~/.codex/config.toml` 的 provider 上下文 | **能装但不放心** |
| `skills-management` | 41★，0.9.0 在 0.2.0-rc.2 验证过，图形化收编各 agent 技能目录 | 备选，暂不装 |

## 理由

1. 现有 23 个技能已验证可用（复验 10/10），桥接的增量收益小。
2. 2★ + 停更的插件引入的是执行面风险：它要读 `~/.codex/skills` 和 `config.toml`，出问题定位成本高于收益。
3. 手动复制可回滚、可审计、无运行时依赖，出问题删目录即可。

## 重估条件

- skillport 正式上 npm 并声明支持 0.2.x；
- codex-bridge 恢复维护、star 与 issue 生态起量；
- Codex 技能增长到手动复制不划算（例如超过 40 个或高频变更）。

## 影响

无文件变更。`~/.dsh/skills` 保持 23 个技能原状；DSH 侧无新增第三方运行时。
