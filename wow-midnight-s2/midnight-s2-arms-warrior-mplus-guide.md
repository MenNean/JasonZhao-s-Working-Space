# 至暗之夜第二赛季：武器战 20+ 大秘境攻略

> 口径：优先读取 Warcraft Logs（简体中文站）`Mythic+ Season 2` 的武器战（Warrior-Arms）排名；能公开看到 23 层的副本取 23 层最高秒伤样本，23 层无公开记录时向下取可见的 20 层样本。WCL 的“秒伤”是整场副本/该榜单统计口径，不等同于单目标木桩。
>
> 重要边界：WCL 页面能直接验证副本、层数、榜单顺序、秒伤、报告中的战斗时长/拉怪起始时间和首领顺序；下文“爆发/减伤时间轴”是把这些实测拉怪节点与武器战技能冷却、首领技能周期结合后的执行方案，属于推荐安排，不把未公开的事件细节冒充成日志实测。

## 一、赛季与武器战基线

WCL 赛季区：<https://cn.warcraftlogs.com/zone/statistics/55>

WCL 赛季汇总中，武器战显示：89.77 赛季积分、112.58 榜单最高值、573,722 条记录。23 层榜单筛选使用 `bracket=22`，20 层使用 `bracket=19`。

### 推荐通用天赋

23 层公开样本反复出现的共同骨架：

- 战斗姿态、御敌姿态、战争机器。
- 快速步伐、吸血打击、胜利在望。
- 风暴之锤、英勇飞跃。
- 英雄天赋：屠戮者；高层样本中屠戮者节点（无情追击、斩杀旋风、机会主义）均为主流。
- 雷霆一击及其强化节点在这些样本中基本不取，说明高层更重视单体/短窗口爆发、移动和自疗；需要大量近战 AOE 的词缀周或特殊路线再临时换回。

WCL 在不同副本的常见天赋占比会变化，但屠戮者、风暴之锤、英勇飞跃、胜利在望和吸血打击是最稳定的可迁移组件。

### 通用爆发循环

`冲锋/英勇飞跃进场 -> 致死打击保持压制窗口 -> 压制/猛击填充 -> 斩杀阶段优先斩杀`。

- **天神下凡/巨人打击窗口**：不要为了“等完美目标”而错过第一波；高层路线通常在第一大怪或首领开怪直接用，第二波靠减伤和药水/饰品错峰。
- **屠戮者窗口**：把斩杀、致死打击和高价值饰品压在窗口内；移动机制开始前提前结束长读条/近战站位。
- **风暴之锤**：优先用于可被队伍集火的危险施法者或首领软狂暴窗口；不是纯粹拿来补单体伤害。
- **胜利在望**：低于约 65% 生命且下一次高伤害前可用时优先按；不要为了“省按钮”死等治疗。
- **英勇飞跃**：既是位移也是爆发接近工具；路线中每次跨平台/转场都要预留一次，除非下一波必然需要冲锋接怪。

### 通用减伤资源

- **御敌姿态**：预判物理爆发、无法规避的全团伤害或治疗被迫移动时切入；伤害窗口结束立即切回战斗姿态。
- **挫志怒吼**：对高物理伤害的首领/大怪群使用，优先覆盖坦克正在吃的重击或全队物理脉冲。
- **盾牌格挡/盾牌反射**：按具体词缀和副本技能安排；需要反射的法术比“单纯顶伤害”更有价值。切盾时要提前结束双手武器爆发，避免在爆发窗口中断输出。
- **法术反射**：高层最值得练习的战士差异点。优先反射可反射的单体重法术/点名，不要把它当通用魔法减伤乱按。
- **胜利在望/吸血打击**：把自疗当作减轻治疗压力和接续下一波的资源，不要等到濒死才按。

## 三、逐本攻略

### 1. 塞塔里斯神庙

WCL 23 层报告用时 **31:53**。首领顺序与实测时间节点：阿德里斯和阿斯匹克斯（约 4:17）、米利克萨（约 6:21）、加瓦兹特（约 19:57）、塞塔里斯的化身（约 27:58）。

**天赋取舍**：通用屠戮者模板；小怪路线若有三目标以上长时间重叠，可把雷霆一击/强化雷霆节点换入，但不要牺牲风暴之锤、英勇飞跃或胜利在望。

**爆发安排**

- 开场第一波大怪直接开第一轮大爆发，英勇飞跃接近并把屠戮者窗口打满；不要把第一轮留给小怪“等首领”。
- 阿德里斯和阿斯匹克斯：第一轮留给双目标同时存活的窗口，优先把致死打击/斩杀压在两目标重叠阶段；阿斯匹克斯读条时用风暴之锤或队伍打断配合。
- 加瓦兹特：把下一轮大爆发预留给能量球/引导后的稳定站桩窗口；移动接球时只打瞬发，回位后再补屠戮者核心技能。
- 塞塔里斯化身：若队伍预计 3 分钟左右战斗，开场轮次和末轮轮次都应覆盖；不要在转阶段前 5 秒才交大招。

**减伤时间轴**

`阿德里斯/阿斯匹克斯重击或雷电点名 -> 御敌姿态 + 挫志怒吼（物理段）`；`加瓦兹特能量球/引导期间 -> 法术反射仅用于可反射点名，不能反射就用御敌姿态`；`化身末段 -> 第二轮挫志怒吼/盾反留给治疗最忙的脉冲`。

WCL 报告的拉怪节点显示加瓦兹特从约 19:57 开始、化身从约 27:58 开始，实际执行时用这两个节点做大招和减伤预留，比按固定秒数更可靠。

### 2. 夺目谷

WCL 23 层报告用时 **29:52**。首领顺序：圣光护卫鲁伊亚、兹欧凯特、圣光猎手伊库兹、光明三位一体；报告中伊库兹约 11:01，鲁伊亚约 17:19，兹欧凯特约 25:56。

**天赋取舍**：通用屠戮者模板，优先保留快速步伐和英勇飞跃应对光圈/分散；雷霆一击只在队伍固定拉大包且需要额外 AOE 时换入。

**爆发安排**

- 前两波孢荒喷射者/光明众花是第一轮最好的 AOE 消耗点；用屠戮者窗口快速压掉远程施法者，避免在光圈/花区中长时间追怪。
- 伊库兹：爆发不要覆盖在全队被迫分散的移动段，等回到首领身边后交致死打击和斩杀；风暴之锤用于关键读条。
- 鲁伊亚：报告中约 17:19 开战，建议把第二轮大招与她的护盾/易伤转换后的稳定段对齐。
- 兹欧凯特：末王通常是最值得留轮次的目标，第三轮能转好就交，不要为了小怪把最后一轮打空。

**减伤时间轴**

高层优先处理光系爆发和移动惩罚：`全队光束/爆炸 -> 御敌姿态`；`可反射的光系点名 -> 法术反射`；`鲁伊亚护盾阶段治疗压力上升 -> 挫志怒吼`。光圈移动期间不要站在近战位硬吃，御敌姿态只解决不可避免的那一段。

### 3. 密谋小径

WCL 23 层报告用时 **32:17**。首领顺序：凯斯媞亚·魔力之心、赞恩·刃悲、歼灭者萨祖克斯、利希尔·烬怒；报告中凯斯媞亚约 5:31、赞恩约 10:23、萨祖克斯约 23:59、利希尔约 27:59。

**天赋取舍**：通用屠戮者模板；移动和短战斗密集，快速步伐、风暴之锤、英勇飞跃不换。雷霆一击仅在路线明确把多组邪能怪叠拉时考虑。

**爆发安排**

- 第一轮优先给受贿的队长/邪能浮龙等高威胁小怪，报告中开场到首领前有连续短战斗，不要把所有资源打在单只低血怪上。
- 凯斯媞亚：短战斗间隔后第一轮通常可再次转好，首领出现即交；赞恩阶段把风暴之锤用在必须停的读条上。
- 萨祖克斯前后有邪能主宰鲁科西等长战斗，第二轮大爆发建议在鲁科西或萨祖克斯二选一，不要两个都空窗。
- 利希尔约 27:59 开战；末王前保留至少一轮屠戮者/饰品，进入末段再交。

**减伤时间轴**

`邪能浮龙/主宰类大怪读条 -> 风暴之锤/法术反射优先`；`赞恩刀刃类物理爆发 -> 御敌姿态 + 挫志怒吼`；`萨祖克斯与利希尔末段连续脉冲 -> 提前切御敌姿态，胜利在望接治疗空档`。该本移动频繁，盾牌反射不要在需要双手输出的短窗口提前切出。

### 4. 毒牙祭坛

WCL 23 层榜单在当前公开筛选下没有可见记录；按用户要求向下取可见的 **20 层**最高伤害样本，Haythor **506,746.4**，报告用时 **26:02**。首领顺序：拉维（约 6:33）、扭缠蛇群（约 12:42/13:00 附近）、祖尔加（约 22:13）。

**天赋取舍**：通用屠戮者模板；吸血打击和胜利在望都保留，毒性持续伤害下不建议为纯 AOE 换掉自疗节点。

**爆发安排**

- 第一轮给双牙蹂躏者/贪婪后裔组合，快速压掉会叠层或持续追人的目标。
- 拉维出现时把致死打击和屠戮者窗口对准首领本体，蛇群阶段用横向移动保持近战覆盖，不要为追小蛇交掉英勇飞跃。
- 祖尔加前的晋升之蛇约 17:35 开始，第二轮大招可用于清掉该波后接祖尔加；若路线把小怪与王重叠，保留屠戮者给祖尔加本体。

**减伤时间轴**

这本的核心是毒性/持续伤害与物理近战混合：`毒性点名/持续掉血 -> 胜利在望、吸血打击；治疗被迫移动时切御敌姿态`；`双牙蹂躏者近战爆发 -> 挫志怒吼`；`祖尔加末段连续伤害 -> 御敌姿态覆盖第一段，盾牌反射只接可反射法术`。不要把法术反射交给不可反射的毒性地面。

### 5. 红玉新生法地

WCL 23 层报告用时 **31:01**。首领顺序：梅莉杜莎·寒妆（约 4:14）、柯姬雅·焰蹄（约 20:51）、基拉卡与厄克哈特·风脉（约 25:24）。

**天赋取舍**：通用屠戮者模板；快速步伐和英勇飞跃是火圈/冰霜转场的核心，不建议为雷霆一击牺牲机动性。

**爆发安排**

- 开场亵渎者德拉加尔/寒妆前小怪时间较长，第一轮应在进入梅莉杜莎前转好；若队伍拉法地小怪进王，屠戮者优先压首领。
- 梅莉杜莎：冰霜机制需要移动，先用瞬发和致死打击，等安全站位后完整打完斩杀段。
- 柯姬雅与基拉卡是本本最值得保留轮次的首领；报告中柯姬雅约 20:51、基拉卡约 25:24，按路线把第二/第三轮压在这两个节点。

**减伤时间轴**

`寒妆冰霜爆发 -> 御敌姿态；可反射冰系单体法术才用法术反射`；`柯姬雅火焰践踏/地面火圈 -> 先走位，无法规避的冲击再切御敌姿态`；`基拉卡风脉末段持续火焰 -> 挫志怒吼 + 胜利在望，末轮不要省减伤`。英勇飞跃应优先留给风火转场，除非队伍明确不需要战士做转火位移。

### 6. 纳洛拉克的洞穴

WCL 23 层报告用时 **31:15**。首领顺序：囤宝狂人（约 4:37）、寒冬哨兵（约 17:35）、纳洛拉克（约 27:14）。

**天赋取舍**：通用屠戮者模板；把吸血打击、胜利在望当作高频自疗链，若队伍治疗压力很低才考虑把其中一个生存节点换成更贪输出的选择。

**爆发安排**

- 囤宝狂人前有领地主母/饥渴之灵连续小怪，第一轮交在领地主母与囤宝狂人重叠或首领本体出现时，不要在空跑阶段浪费屠戮者。
- 寒冬哨兵前的决意化身从约 10:53/14:59 开始，第二轮优先用于清化身并在 17:35 接王。
- 纳洛拉克约 27:14 开战，末王保留第三轮；若战斗超过 3 分钟，按“开场轮 -> 寒冬/转阶段轮 -> 纳洛拉克末段轮”分配。

**减伤时间轴**

`囤宝狂人重击/近战叠层 -> 御敌姿态 + 挫志怒吼`；`寒冬哨兵冰霜脉冲 -> 法术反射只接可反射单体，群体脉冲用御敌姿态`；`纳洛拉克变身/末段连续近战 -> 挫志怒吼与胜利在望错开，避免两者同时空窗`。这本的减伤价值高于多打一发填充技能，治疗被迫转火时优先保命。

### 7. 虚空之痕竞技场

WCL 23 层榜单当前公开筛选不可见；按可见的 **20 层**样本，羊高丷 **447,232.2**，报告用时 **26:59**。首领顺序：塔兹拉尔（约 6:57）、阿特洛苏斯（约 15:57）、煞戎努斯（约 23:11）。

**天赋取舍**：通用屠戮者模板；保留快速步伐、英勇飞跃处理竞技场转场，雷霆一击只在大包路线明确需要时换入。

**爆发安排**

- 开场不屈的埃吉拉、布鲁托克先出现，第一轮大招优先压掉最危险的近战/施法者组合。
- 塔兹拉尔约 6:57，第一轮转好就交；阿特洛苏斯约 15:57，第二轮以首领本体为主，不要被 12:19/12:40 的小怪短战斗骗走。
- 煞戎努斯约 23:11，第三轮和饰品应尽量覆盖末王；跨场移动时英勇飞跃只在真正需要时使用。

**减伤时间轴**

`布鲁托克/不屈埃吉拉物理重击 -> 挫志怒吼`；`塔兹拉尔法术点名 -> 法术反射；不可反射时御敌姿态`；`阿特洛苏斯虚空脉冲 -> 御敌姿态 + 胜利在望`；`煞戎努斯末段 -> 盾牌反射/御敌姿态按技能类型错开`。该本场地常让近战短时间离开目标，减伤要按“回位前后”安排，不能只看冷却好了没有。

### 8. 诸王之眠

WCL 23 层报告用时 **32:01**。首领顺序：黄金风蛇（约 3:18）、殓尸者姆沁巴（约 14:59）、部族议会（约 20:37）、达萨大王（约 27:40）。

**天赋取舍**：通用屠戮者模板；黄金风蛇和部族议会的双目标/多目标阶段可短暂获得雷霆一击收益，但高层仍优先保留风暴之锤、胜利在望和英勇飞跃。

**爆发安排**

- 黄金风蛇前的活化守卫/黄金风蛇是第一轮最佳 AOE 与单体混合窗口；不要把屠戮者留到 3:18 之后才开。
- 姆沁巴约 14:59，前面大王与构造体战斗较多，第二轮通常应在姆沁巴前后预留；处理棺材/移动机制时以瞬发为主。
- 部族议会约 20:37，优先把致死打击打在可被集火的目标上，风暴之锤帮助打断危险施法。
- 达萨大王约 27:40，末王轮次不要被 25:37 的祖尔之影小怪提前消耗。

**减伤时间轴**

`黄金风蛇物理/毒性混合 -> 御敌姿态，毒性持续段用胜利在望`；`姆沁巴强制移动/治疗压力 -> 提前切御敌姿态，不要等生命线见底`；`部族议会重击 -> 挫志怒吼`；`达萨末段连续物理爆发 -> 挫志怒吼与盾牌格挡错峰，最后再用法术反射处理可反射法术`。

## 四、按钥匙层数执行的优先级

### 20 层

目标是稳定清场：保留一轮大招给每个首领，减伤优先覆盖首领第一轮重击；不要为了榜单秒伤牺牲打断、走位或自疗。

### 21-22 层

开始按 WCL 报告的拉怪起始时间规划冷却：首领前 30-45 秒不要无意义交第二轮，确保能覆盖首领或关键大怪；法术反射从“有就按”变为“只反高价值技能”。

### 23+ 层

每本只允许极少数失误：

1. 开钥匙前写下 3 个必须用风暴之锤/法术反射的技能。
2. 写下第二轮大招要给的具体首领，而不是“好了就按”。
3. 每次进首领前确认御敌姿态、挫志怒吼、胜利在望至少有一个可用。
4. 以报告中的真实拉怪起始节点校准路线，不照搬固定秒数；队伍击杀速度变化时，按“首领/高危大怪顺序”重新分配。

## 五、如何在 WCL 复盘自己的时间轴

1. 打开对应报告，先看 `Bosses and Trash`，记录每个首领/高危小怪的开始时间。
2. 切到自己的武器战来源，检查天神下凡/巨人打击、屠戮者窗口、风暴之锤、法术反射、御敌姿态、挫志怒吼和胜利在望是否覆盖了对应节点。
3. 先修复“减伤空窗导致死亡”和“法术反射错目标”，再修复爆发错位；高层的实际收益通常高于多按一两个填充技能。
